# The Long Watch: web

The story and explorer for The Long Watch, a harmonised 2001–2024 global fire record. Next.js 16 (App Router) with next-intl (English and French), a MapLibre globe, Observable Plot charts and Scrollama, deployed to Cloudflare Workers through OpenNext.

## Pages

| Route | What it is |
|---|---|
| `/[locale]` | The scrolling story: ten satellite-narrated chapters over a sticky globe |
| `/[locale]/explore` | The explorer |
| `/[locale]/method` | How the record is built, with the hold-out scoreboard |

`locale` is `en` or `fr`. Messages live in `messages/en.json` and `messages/fr.json`.

## Develop

```bash
npm install
npm run dev        # copies the MapLibre worker into public/ first, then starts next dev
npm run lint
npx next typegen && npx tsc --noEmit   # route types (LayoutProps etc.) are generated by Next
```

## Data

The app reads small JSON files committed in `src/data/` and `public/data/`. They are exported from the pipeline by `../pipeline/web_seed.py`, which needs the pipeline outputs (`data/truth`, `data/regions`, `data/grid`, `data/harmonized/ml_metrics.json`) to run. Every number on screen comes from those files.

## Deploy (Cloudflare)

```bash
npm run preview    # build with OpenNext and run locally in workerd
npm run deploy     # build and deploy the flamesense-web Worker
```

The R2 bucket `flamesense-web-cache` (incremental cache) must exist before the first deploy.
